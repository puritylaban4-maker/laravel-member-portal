# KHWWC Member Dashboard Frontend

## Goal
Build the member dashboard first, using the uploaded KHWWC logo and dashboard reference while delivering a more polished, professional, mobile-first experience.

## What I’ll build
- A premium KHWWC member dashboard at `/`, ready to be connected to the existing Laravel data contract.
- A responsive desktop layout with a compact navigation rail and a focused mobile layout with bottom navigation.
- Member identity, membership status, wallet balance, contribution summary, next due date, penalty balance, progress, quick actions, and recent activity.
- Functional presentation interactions: notification panel, balance visibility, profile menu, quick-action feedback, and mobile navigation states.
- The supplied KHWWC logo as the primary brand asset.

## Visual direction
- Deep charcoal and warm off-white surfaces, with KHWWC orange, red, green, and gold accents.
- Crisp editorial typography, restrained shadows, fine borders, and compact financial-data hierarchy.
- Cleaner and more credible than the reference: less glow, stronger spacing, better contrast, and clearer action priority.

## Technical details
- Keep the work frontend-only; use realistic display data until the existing Laravel frontend/API source is supplied.
- Preserve the verified role names, route families, auth boundaries, and Laravel endpoint contracts from the master brief.
- Define all colors and visual values through the project design system.
- Add page-specific metadata and verify desktop and mobile rendering.
